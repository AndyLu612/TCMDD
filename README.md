# 台灣海岸垃圾數據看板

這是一個以台灣海岸垃圾議題為主題的互動式網頁看板，透過地圖、圖表、問答遊戲和減塑計分板，讓使用者更容易了解海洋廢棄物的分布與影響。

## 專案功能

- 全台海廢熱點地圖：點擊不同區域，查看該區海岸垃圾量。
- 污染程度標籤：依照垃圾量顯示低污染、中度污染、中高污染或高污染熱點。
- 動態圖表分析：使用 Chart.js 顯示垃圾成分圓餅圖與各區域垃圾量長條圖。
- 地圖與圖表連動：點擊地圖區域時，長條圖會自動切換並高亮該區資料。
- 海廢冷知識測驗：提供選擇題、答題回饋、進度條與最終得分。
- 個人減塑計分板：勾選日常減塑行動後，自動計算減碳貢獻並顯示鼓勵訊息。
- 資料說明區：說明本看板為環境教育展示用途，數據為模擬資料。

## 使用技術

- HTML：建立網頁內容與區塊結構。
- CSS：設計畫面樣式、卡片版面、按鈕、地圖互動效果與進度條。
- JavaScript：控制地圖點擊、圖表切換、測驗流程與減塑計分。
- Chart.js：產生圓餅圖與長條圖。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。

線上展示網址：

```text
https://tcmdd.vercel.app/
```

如果使用本機伺服器，也可以在專案資料夾中啟動靜態網頁服務後開啟：

```bash
python3 -m http.server 8000
```

然後在瀏覽器進入：

```text
http://127.0.0.1:8000
```

## 備註

本專案中的海岸垃圾量與減碳數據為模擬資料，主要用於環境教育、課堂展示與互動式網頁練習。
